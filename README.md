# Ларри Тоут — фильмы на Remotion

Два ролика в одном визуальном языке: стилизованная flat-графика, многослойный
параллакс и шарнирные персонажи через `transform`. Вся графика — процедурный
SVG/CSS внутри React-компонентов, внешних ассетов нет. Оба саундтрека
синтезируются скриптами и синхронизированы с монтажом.

| Композиция | Длительность | Что это |
|---|---|---|
| `FrogKnightTeaser` | 15 с | Тизер: рыцарь-лягушка скачет на коне |
| `Act1Birth` | 45 с | Акт I «Рождение»: рождение, взросление, посвящение |

## Запуск

```bash
npm install
npm run studio      # интерактивный редактор Remotion Studio
npm run build       # тизер     -> out/frog-knight-teaser.mp4
npm run build:act1  # акт I     -> out/act1-birth.mp4
```

`npm run audio` пересобирает оба саундтрека (`public/score.mp3`, `public/act1.mp3`).
`npm run typecheck` — проверка типов.

Если Chrome не находится автоматически, укажите его явно:

```bash
npx remotion render FrogKnightTeaser out/teaser.mp4 --browser-executable=/path/to/chrome
```

## Раскадровка акта I (`Act1Birth`)

| Кадры | Секунды | Сцена | Что происходит |
|---|---|---|---|
| 0–452 | 0:00–0:15 | `Birth` | Туманное болото под луной. На кувшинке светится икра, вспышка — и появляется лягушонок. Камера всё это время медленно наезжает, к концу вдвое крупнее. |
| 450–902 | 0:15–0:30 | `Training` | Быстрый монтаж взросления: 14 планов, по 3–4 на каждый из четырёх сезонов, примерно по секунде. Он растёт от плана к плану, на середине появляется шлем. |
| 900–1350 | 0:30–0:45 | `Knighting` | Тронный зал: свет из витражей, король кладёт меч на плечи — правое, потом левое, — Ларри встаёт рыцарем. Титр. |

Монтаж тренировок задан таблицей `SHOTS` в `src/scenes/act1/Training.tsx` —
сезон, действие, возраст, кадрирование. Порядок и тайминг планов меняются
правкой этой таблицы, анимация подстраивается сама.

## Как устроена анимация

**Всё детерминировано.** Ни `Math.random()`, ни `Date.now()` — только
`useCurrentFrame()` и `random(seed)` из Remotion, поэтому любой кадр
рендерится одинаково при любом порядке рендера.

**Галоп.** `Horse.tsx` считает фазу шага в оборотах (`stride`), каждая нога —
бедро → голень → копыто, углы берутся от `sin(2π·stride + phase)`. Параметр
`gait` (0…1) глушит размах: 0 — конь стоит, 1 — полный галоп. `rear`
поднимает коня на дыбы вместе со всадником, потому что оба лежат под одним
`transform`.

**Параллакс.** `Band` повторяет один тайл трижды и сдвигает его по модулю
ширины. Гребни холмов строятся суммой синусов с целыми частотами относительно
ширины тайла — стыки бесшовные. Слои едут со скоростями от 0.08 (дальние
холмы) до 1.9 (камыш).

**Персонажи.** Конь и лягушка-боец устроены одинаково: цепочка костей, каждая
вращается относительно родительской, поза — чистая функция от прогресса
действия. У бойца семь действий (`swing`, `leap`, `run`, `strike`, `raise`,
`balance`, `kneel`), и любой план монтажа — это пара «действие + сезон».
Для дальних планов тот же персонаж прогоняется через `<Flat/>`: SVG-фильтр
`feColorMatrix` схлопывает цвет, сохраняя альфу, — один набор графики работает
и как цветной герой, и как контровой силуэт.

**Звук.** `scripts/synth.mjs` — синтезатор, считающий дорожку сэмпл за
сэмплом. Тизер: дрон, шумовые накаты, удары копыт, гром, райз, бум. Акт I:
болотный дрон с каплями, ритмичный монтажный пульс с остинато и литаврами на
каждой склейке, и коронационная тема — ход i–VI–III–VII–V, разрешающийся в
мажорную тонику ровно в тот кадр, где Ларри встаёт. Удары привязаны не «на
слух», а к тем же номерам кадров, по которым режется картинка: копыта — к
функции `stride` из сцены, монтажные акценты — к границам планов, колокол —
к касанию меча о плечо. MP3 кодируется тем ffmpeg, который уже входит в
состав Remotion.
