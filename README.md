# Рыцарь-Лягушка — 15-секундный тизер

Проект на [Remotion](https://remotion.dev): 15 секунд, 1920×1080, 30 fps.
Вся графика — процедурный SVG/CSS внутри React-компонентов, внешних ассетов
нет. Саундтрек генерируется скриптом и синхронизирован с монтажом.

## Запуск

```bash
npm install
npm run studio   # интерактивный редактор Remotion Studio
npm run build    # рендер в out/frog-knight-teaser.mp4
```

`npm run audio` пересобирает саундтрек (`public/score.mp3`).
`npm run typecheck` — проверка типов.

Если Chrome не находится автоматически, укажите его явно:

```bash
npx remotion render FrogKnightTeaser out/teaser.mp4 --browser-executable=/path/to/chrome
```

## Раскадровка

| Кадры | Секунды | Сцена | Что происходит |
|---|---|---|---|
| 0–96 | 0.0–3.2 | `ColdOpen` | Спящее болото, луна, силуэт всадника. Камера медленно наезжает. |
| 92–218 | 3.1–7.3 | `Ride` | Галоп вдоль берега: параллакс в пять слоёв, пыль из-под копыт, светлячки, камыш на переднем плане. |
| 214–304 | 7.1–10.1 | `Portrait` | Крупный план героя: моргание, кваканье, вспышка молнии, поднимающийся клинок. |
| 300–374 | 10.0–12.5 | `Charge` | Конь встаёт на дыбы на фоне луны, линии скорости, удар. |
| 370–450 | 12.3–15.0 | `TitleCard` | Титр с золотым бликом, подзаголовок, «Скоро». |

Сцены перекрываются на несколько кадров, стыки закрыты короткими
кросс-фейдами (`Dissolve` в `src/Teaser.tsx`).

## Структура

```
src/
  index.ts               registerRoot
  Root.tsx               композиция FrogKnightTeaser (450 кадров, 30 fps)
  Teaser.tsx             тайминг сцен, зерно плёнки, чёрные полосы
  theme.ts               палитра, шрифты, размеры
  components/
    Horse.tsx            конь в профиль: шарнирные ноги, грива, хвост
    FrogKnight.tsx       голова лягушки (шлем, глаза, моргание) и всадник
    MountedKnight.tsx    конь + всадник в общей системе координат
    Rider.tsx            постановка всадника на линию земли
    Environment.tsx      небо, луна, холмы, вода, туман, светлячки, камыш
    Effects.tsx          виньетка, зерно, вспышки, пыль, линии скорости
    Titles.tsx           титры и логотип
  scenes/                пять сцен
scripts/
  make-audio.mjs         генерация саундтрека
```

## Как устроена анимация

**Всё детерминировано.** Ни `Math.random()`, ни `Date.now()` — только
`useCurrentFrame()` и `random(seed)` из Remotion, поэтому любой кадр
рендерится одинаково при любом порядке рендера.

**Галоп.** `Horse.tsx` считает фазу шага в оборотах (`stride`), каждая нога —
бедро → голень → копыто, углы берутся от `sin(2π·stride + phase)`. Параметр
`gait` (0…1) глушит размах: 0 — конь стоит, 1 — полный галоп. `rear`
поднимает коня на дыбы вместе со всадником, потому что оба лежат под одним
`transform`.

**Параллакс.** `Band` повторяет один тайл трижды и сдвигает его по модулю
ширины. Гребни холмов строятся суммой синусов с целыми частотами относительно
ширины тайла — стыки бесшовные. Слои едут со скоростями от 0.08 (дальние
холмы) до 1.9 (камыш).

**Звук.** `scripts/make-audio.mjs` синтезирует дорожку сэмпл за сэмплом:
низкий дрон, шумовые накаты, удары копыт, гром, разгонный райз и финальный
бум. Удары копыт эмитятся ровно тогда, когда `stride` из сцены пересекает
одну из четырёх долей галопа, — картинка и звук совпадают по построению.
MP3 кодируется тем ffmpeg, который уже входит в состав Remotion.
